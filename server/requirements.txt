# MIDI/MusicXML/Score21 export, practice sets) works fine on this core set.
#
# For the optional offline DDSP render + FFT reverb path, install
# requirements-ddsp.txt on top. That file pins Magenta/DDSP and pulls
# ~1.5 GB of TF + librosa; do not install it on the HF free tier.
