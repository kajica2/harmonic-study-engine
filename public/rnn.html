How it works

Spec

The engine lazy-imports @magenta/music, instantiates MusicRNN, and runs continueSequence() on a quantized seed.

If the checkpoint fetch fails (CDN, CORS, or sandbox), the engine swaps in a deterministic melodic variation built from the trumpet-etude idioms — so the page never lies about playback state.
