# AGENTS.md

Harmonic Study Engine — React 19 + Vite 6 + Tailwind 4 SPA (trumpet practice engine: personas, backing tracks, composition tools, masterclass catalog). Optional FastAPI backend. Full system map in `docs/ARCHITECTURE.md`; recipes in `docs/DEVELOPING.md`.

## Commands

```bash
npm run lint        # tsc --noEmit — there is NO eslint
npm test            # vitest run — 899 passed / 1 skipped (77 files)
npm run build       # TWO builds: vite.rnn.config.ts first, then main vite build
npm run check:paths # tsx scripts/check-path-bars.ts — bar-count invariant (36/36 OK)
npm run test:py     # backend pytest (prefers .venv/bin/python)
npm run test:e2e    # Playwright — REQUIRES `npm run build` first (serves dist/ on :4173)
npm run dev         # bash dev.sh — boots FastAPI :8765 + Vite :5173, opens browser
npm run dev:vite    # frontend only
npm run dev:backend # uvicorn server.app:app on :8765
```

Gate order (CI mirrors this): `npm run lint` → `npm test` → `npm run build`. Run all three before committing.

## Testing gotchas

- **New DOM-touching test files MUST be added to `JSDOM_FILES` in `vitest.config.ts`.** Vitest 5 multi-project mode IGNORES per-file `// @vitest-environment jsdom` comments. Pure-logic tests run in the node project automatically.
- **Count pins fail CI if you change the underlying data without updating them:**
  - `tests/count-tunes.test.js` pins `tunesCount()` to 40 (masterclass catalog size)
  - `tests/pathBriefing.test.ts` pins `curatedBriefingCount()` to 12 — bump when enabling a masterclass tune with a curated `objective`
  - `assets/check-links.cjs` (drift gate, runs FIRST in CI) asserts persona/tune counts cited in README.md and `src/magenta/personaProfiles.ts` match SPEC.md
- **`tests/no-debug-logs.test.ts` bans `console.log/info/debug` in `src/`.** Only `console.warn/error` allowed (error-path reporting).
- React components are intentionally NOT unit-tested (audio-engine singletons make mocking low-ROI). Pure logic lives in `src/lib/` and is tested in the node env.

## Generated code — do not edit by hand

- `src/lib/studies.ts` is auto-generated by `scripts/ingest_standards.py`. Path data fixes (e.g. bar counts) must be mirrored in the script's SONGS dict, not just the TS output.
- `scripts/check-path-bars.ts` verifies every path is within MIN/MAX_PATH_BARS.

## Masterclass enablement workflow

To enable a catalog tune (see MASTERCLASS_TODO.md):
1. Author/verify the `study-<slug>` HarmonicPath in `src/lib/paths.ts` (RAW_PATHS)
2. Flip `inApp: true` in `src/data/masterclass.ts` and add a curated `objective`
3. Bump the `curatedBriefingCount` pin in `tests/pathBriefing.test.ts`
4. `npm run lint` + `npm test` + `npm run build`
5. Verify the id ships: `grep -o "<id>" dist/assets/index-*.js`
6. Commit: `feat(masterclass): enable <Title> — <id> path + flip inApp`

## Architecture essentials

- `src/App.tsx` is a ~3300-line monolith owning playback state, persona/voicing/tempo, keyboard/MIDI wiring. Most UI changes touch it.
- Audio engines are module-level singletons: `audioEngine` (`src/lib/audio.ts`), `rhythmEngine` (`src/lib/rhythm.ts`), `backingEngine` (`src/lib/backingEngine.ts`), `playbackClock` (`src/lib/playbackClock.ts`).
- **Metronome click**: `rhythmEngine.playStep()` fires `audioEngine.playMetronomeClick()` gated on `metronomeEnabled`. App.tsx syncs the UI toggle via `useEffect(() => rhythmEngine.setMetronomeEnabled(metronomeOn), [metronomeOn])`. The backing beat styles are owned by `backingEngine` — muting the click does NOT mute the backing track (by design).
- `src/lib/` = pure, testable logic; `src/components/` = React UI; `src/data/` = JSON/TS data (personas.json, masterclass.ts, styles/, formTemplates/, quizzes/).
- The `@` path alias resolves to repo ROOT (`.`), not `src/` — but is rarely used; imports are relative.

## Build / deploy

- `npm run build` runs the RNN config build first (`vite.rnn.config.ts`), then the main build. Both must pass.
- Build stamps `__APP_COMMIT__` / `__APP_BUILD_TIME__` (vite.config.ts `define`) — read by `src/lib/buildInfo.ts`, rendered by `BuildFooter.tsx`. Vercel sets `VERCEL_GIT_COMMIT_SHA`; local builds shell out to git.
- Vercel auto-deploys on push to `main` (project `harmonic-study-engine`). Preview URLs redirect to Vercel SSO when unauthenticated; the production alias `https://harmonic-study-engine.vercel.app` is public.
- Backend (FastAPI) is optional and runs in degraded mode without DDSP. `VITE_DDSP_API` defaults to `http://127.0.0.1:8765`. `VITE_OPENROUTER_API_KEY` is build-time and optional (see `.env.example`).
