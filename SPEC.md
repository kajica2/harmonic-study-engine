## How the gate works

`assets/check-links.js` is a pure-Node script (no deps) that walks the
files listed above and asserts every cited count matches its source of
truth. It's run by GitHub Actions on every push to main and every PR.

Failure shape: the script prints every violation as `file:line —
expected X, got Y` and exits 1. CI red. Local: `node assets/check-links.js`.

## Surface inventory

The repo has three user-facing surfaces:

| Surface | Path | Notes |
|---|---|---|
| Main app | `/` | React 19 SPA, `src/App.tsx` |
| Engine v2 | `/engine` | `public/sainted-word-records.html`, redirect via `vercel.json` |

in `public/` are in `vercel.json`. Keep that file's source list and
the `public/` directory in sync — adding a surface means both files.

## Deploy env vars

| Var | Default | Set on | Used by |
|---|---|---|---|
| `VITE_OPENROUTER_API_KEY` | unset | Vercel | Cloud Gemini/OpenRouter generators |
| `VITE_DDSP_API` | `http://127.0.0.1:8765` (dev) / unset (prod) | Vercel | DDSP backend base URL |
| `DDSP_CORS_ORIGINS` | `localhost:5173` etc. | Render | CORS allowlist |
| `PYTHON_VERSION` | `3.11.10` | Render | Python runtime pin |

## What this repo does NOT do

- No Docker. Render uses the native Python runtime; local dev uses
  `bash dev.sh` with a self-bootstrapping `.venv`.
- No DDSP / Magenta / TF in the default install. The lean backend
  boots in degraded mode without them; install `server/requirements-ddsp.txt`
  on top to opt in.
- No CI secrets. `.github/workflows/test.yml` runs lint + vitest +
  pytest with no environment variables set.
